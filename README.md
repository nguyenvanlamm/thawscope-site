# thawscope-site

Landing page, privacy policy and support page for **Thawscope**, an offline word puzzle for iPhone.

Live at https://nguyenvanlamm.github.io/thawscope-site/ (GitHub Pages, served from `main`, no build step).

- `index.html` — the landing page
- `privacy.html` — the App Store privacy policy URL
- `support.html` — the App Store support URL
- `assets/` — screenshots and the share card, made from the game's own screens and icon

Every push to `main` republishes the site.
